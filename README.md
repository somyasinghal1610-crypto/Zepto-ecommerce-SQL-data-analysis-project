# Zepto E-commerce SQL Data Analysis

SQL data analysis project using PostgreSQL to uncover product, pricing, inventory, discount, and business insights from Zepto's e-commerce dataset.

---

# 📌 Overview

This project demonstrates an end-to-end SQL data analytics workflow using PostgreSQL. The analysis focuses on importing raw Zepto e-commerce data, cleaning and exploring the dataset, and solving real-world business problems using SQL queries.

The objective is to transform raw product data into meaningful business insights that support data-driven decision-making.

---

# 💼 Business Problem

Zepto aims to better understand its product catalog, pricing strategy, discounts, and inventory to improve business performance and optimize decision-making.

This project answers business questions through SQL by analyzing product data and identifying meaningful trends and patterns.

---

# 📁 Dataset

The dataset contains Zepto product information, including:

- Product Name

- Discount
- Weight
- Availability
- Product Attributes

The dataset was:
